# 超导量子比特「直观模拟展示」小软件 — 选型调研报告

- 日期：2026-09-22
- 目标：判断是否需要为「超导量子比特原理的直观模拟展示」再做一款软件，还是用已有工具即可
- 判据需求（用户确认）：
  - **① 教学式交互演示**：transmon / 约瑟夫森结 / 能级与非谐性 / Bloch，拖参数即时反馈
  - **② 动力学过程可视化**：Rabi / Ramsey / T1 / T2、脉冲驱动
  - **③ 参数扫描与静态图**：能级-磁通、色散、频谱
- 未列为核心判据：从电路图做量子化、芯片版图/流片设计（仍会出现在盘点中）

---

## 1. 一句话结论

**结论：混合（薄自研壳 + 复用求解器）。**

已有工具在「算」上已经很强（scqubits / QuTiP 完全覆盖 ③，也能算 ②），但在「直观展示原理」（①）以及 ② 的演示形态上，**没有现成产品**能同时做到「超导比特物理 + 交互教学 + 动力学可视化」。完全自研求解器没有意义；完全用现成组合则 ① 无法满足。

推荐路径：**自研一个薄的交互可视化层（形态见《开发规划》），把 scqubits / QuTiP 当作求解后端**。

## 3. 分项盘点

### 3.1 scqubits — 超导比特光谱与矩阵元

- **定位**：J. Koch / P. Groszkowski 维护的超导量子比特专用库；算常见比特能谱、能级随外参变化、矩阵元，并与 QuTiP 组成耦合复合系统。
- **开源 / 形态**：开源（[scqubits/scqubits](https://github.com/scqubits/scqubits)）；Python 库；数值 NumPy/SciPy，作图 Matplotlib。论文：Quantum 5, 583 (2021)。
- **能力**：transmon / fluxonium 等比特模型、能谱扫参、`t1_cap` 等弛豫通道、与谐振腔耦合、导出到 QuTiP。
- **能力边界**：**输出是 matplotlib 静态图**，没有「拖滑块即时反馈」的交互产品层；没有教学叙事（势阱、约瑟夫森结物理动画等）；动力学要自己搭。
- **对三类需求**：③ **完全够用**；② 计算部分够、展示要自建；① 不满足。
- **验证**：仓库 README 明确「plot energy levels as a function of external parameters, calculate matrix elements, interface to QuTiP」；配套 [scqubits-examples](https://github.com/scqubits/scqubits-examples) 为 Jupyter notebook 示例。

### 3.2 QuTiP 及其可视化 / QIP 组件

- **定位**：通用开放/封闭量子系统动力学工具箱，科研与教学都在用。
- **开源 / 形态**：开源（[qutip/qutip](https://github.com/qutip/qutip)）；Python 库；Matplotlib 出图。numFOCUS 关联项目。
- **能力**：含时哈密顿量、主方程/Lindblad、`qutip.Bloch`（Bloch 球）、能级/期望值绘图；可与 scqubits 对接。
- **qutip-qip**（[qutip/qutip-qip](https://github.com/qutip/qutip-qip)）：量子线路 + **脉冲级处理器模型**，文档明确包含 *Superconducting Qubits* 设备模型，可做噪声脉冲仿真并对比保真度。这对 ② 是现成物理引擎。
- **可视化部件**：QuTiP 生态曾提供 Jupyter 交互部件（Bloch 等）。本次调研中 `qutip-jupyter-widgets` 仓库 404，**信息缺口**：部件是否更名/并入主线未核实到权威页面。Matplotlib 的 `qutip.Bloch` 本身确定可用。
- **能力边界**：默认形态是 notebook/script + matplotlib，**不是**「面向理解原理的交互小软件」；通用性强，超导比特的「势阱/约瑟夫森结/非谐性」教学包装需要自建。
- **对三类需求**：② **计算强、展示中**；③ 中；① 弱。

### 3.3 Qiskit 及 Qiskit Dynamics

- **Qiskit**（[Qiskit/qiskit](https://github.com/Qiskit/qiskit)）：门级线路 SDK、转译、primitives。学习通用量子计算合适，**不覆盖**超导比特内部物理（EJ/EC、能级非谐性）。
- **Qiskit Dynamics**（[qiskit-community/qiskit-dynamics](https://github.com/qiskit-community/qiskit-dynamics)）：含时系统建模与求解（frame 变换、RWA、NumPy/JAX 后端）。**仓库已标注 DEPRECATED，不再积极维护**。
- **对三类需求**：门级对 ① 有帮助但抽象；② 靠 Dynamics 但已弃维护；③ 弱。
- **建议**：不把 Qiskit Dynamics 作为新项目的主求解依赖；门级交互若需要，可只借鉴 Composer/Quirk 的产品形态。

### 3.4 交互式量子模拟器（产品形态参照）

**Quirk**（[Strilanc/Quirk](https://github.com/Strilanc/Quirk)，[algassert.com/quirk](https://algassert.com/quirk)）

- 浏览器内拖拽线路、**实时模拟与动画**、行内状态显示、≤16 qubits、电路可书签化。
- **强在产品体验**：无需安装、即时反馈、可视化密度高。
- **边界**：qubit 是抽象的——没有 transmon、约瑟夫森结、能级结构、色散读出等超导物理。测量实现还有已知限制（README 声明）。
- **对需求**：① 对「量子比特行为」很强，对「超导比特原理」不满足。

**IBM Quantum Composer**

- Web 线路编辑与模拟（IBM Quantum 云文档入口 [quantum.cloud.ibm.com](https://quantum.cloud.ibm.com/)）。本次直接抓取 Composer 页返回 403，**信息缺口**：页面细节以公开产品定位为准——门级线路可视化 + Bloch + 概率条，登录后可跑模拟。
- **对需求**：同 Quirk，抽象量子门层，不是超导电路物理教学。

### 3.5 芯片设计 / 量子化工具（科研向）

**Quantum Metal（Qiskit Metal）**（[qiskit-community/qiskit-metal](https://github.com/qiskit-community/qiskit-metal)）

- 超导量子芯片 **设计** 框架：平面几何、GDS 导出、可选 MetalGUI、HFSS/Q3D、LOM、gmsh 网格。已从 IBM 移交社区（QDC），包名 `quantum-metal`。
- **对需求**：解决「芯片长什么样、参数怎么提取」，不解决「原理如何直观演示」。①② 均不满足，③ 的图是设计分析图。

**pyEPR**（[zlatko-minev/pyEPR](https://github.com/zlatko-minev/pyEPR)）

- Energy-Participation Ratio 量子化：从 HFSS 本征模（或给定频/L/φ_zpf）得到完整量子哈密顿量、dressed 频率、非谐性、χ 矩阵。无 HFSS 也可做数值对角化（Tutorial 6）。
- **对需求**：科研级量子化很强；输出是分析图与数据，不是交互教学演示。

**QuCAT（Quantum Circuit Analyzer Tool）**

- GitHub 检索可见「Quantum Circuit Analyzer Tool」仓库及配套 **Web 电路编辑器**（为 Qucat 仿真生成 netlist）。定位为超导电路（C/L/J）量子化分析。
- **信息缺口**：本次未能打开其主页/文档做深度核验，能力以「电路分析/量子化工具」定性；**不宜夸大**其可视化与交互能力。
- **对需求**：偏 ③ 与电路量子化；① 的「原理演示」不是它的产品目标。

### 3.6 教学向 Bloch / 单比特可视化项目

GitHub 检索可见多类：

- 「简单交互单 qubit Bloch 可视化」（含 Streamlit、Web 3D、多款 Interactive Bloch sphere）
- 「含 Bloch 显示的交互量子模拟器」
- 「双 qubit 模拟器 + 实时 Bloch」

**共性边界**：几乎都是**抽象 qubit + 门**的教学，不包含约瑟夫森结势阱、EJ/EC、transmon 能级非谐性、色散读出等超导比特特有的物理。

### 3.7 超导比特专用模拟脚本 / notebook

GitHub 检索可见多条研究向项目（示例描述）：

## 4. 以三类需求做最终判断

### ① 教学式交互演示 — **已有不满足**

| 子项 | 已有工具表现 |
|---|---|
| 约瑟夫森结势阱 / 余弦势与抛物近似 | 无现成交互产品；散落在 notebook |
| transmon 能级、非谐性 α，EJ/EC 滑块 | scqubits 能算能画，无「拖参数即时反馈」产品层 |
| 能级跃迁、驱动选择定则 | 多为论文/讲义图 |
| Bloch 球 + 超导能级结构联动 | Bloch 有，联动无 |

Quirk / Composer 的交互体验是范本，但物理抽象层不对；scqubits 的物理对，但展示层不对。**两者拼起来仍缺一层专门的「原理演示壳」。**

### ② 动力学过程可视化 — **已有半满足（算有，看无）**

- Rabi / Ramsey / T1 / T2、脉冲驱动：**QuTiP + qutip-qip**（或已弃维护的 Qiskit Dynamics）都能做可靠数值。
- 但「直观展示」——时间轴动画、与能级/Bloch 联动、拖脉冲参数立刻看到 Rabi 振荡变化——**需要自建展示层**。
- 结论：**物理引擎可复用，产品层要自己做。**

### ③ 参数扫描与静态图 — **已有完全满足**

- 能级-磁通、色散移、频谱、矩阵元扫参出图：**scqubits 为首选**，QuTiP 作补充。
- 唯一限制是 matplotlib 静态图的「不交互」，若你接受 notebook 工作流，**此项不必自研**。

## 5. 明确选型结论（三选一）

```
结论：混合（薄自研壳 + 复用求解器）
```

| 备选 | 判定 | 理由 |
|---|---|---|
| 直接用已有工具组合 | **否** | ① 教学交互演示无产品级现成方案；② 只有计算没有直观展示。若接受「只用 notebook 手写 matplotlib」，可只满足 ③，与你「直观展示」的初衷不符。 |
| 需要自研（含自研求解器） | **否** | 能谱/动力学求解已有成熟库（scqubits / QuTiP），自研求解器成本高、易错、无增量价值。 |
| **混合（薄自研壳 + 复用求解器）** | **是** | ③ 直接用 scqubits；② 用 QuTiP / qutip-qip 当引擎；① 与 ② 的「直观展示」由薄壳层承担。缺口明确、复用充分、工作量可控。 |

### 推荐技术路径（概要，详见《开发规划》）

1. **求解层（不自研）**：scqubits（能谱/矩阵元/弛豫速率）+ QuTiP（含时动力学、主方程、Bloch）；可选 qutip-qip 做脉冲级比特-腔模型。
2. **展示层（自研薄壳）**：交互式参数控件 + 联动视图（势阱/能级/Bloch/时域波形），满足 ①②。
3. **静态图（不自研）**：③ 保留 scqubits/matplotlib 工作流，或在壳层中提供导出。
4. **明确不做**：不自研 ODE/对角化求解器；不把 Quantum Metal/pyEPR 的芯片设计链路放进 MVP。
