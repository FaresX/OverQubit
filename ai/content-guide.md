# 教学内容写作标准（Notebook 正文）

> 目标：**详细、生动、原理讲透**。这份是「怎么写」的规范；踩坑与修复见 `lessons.md`。
> 每个 notebook 的文本块都按下面的骨架来，四层递进：**图像 → 机制 → 定量 → 代价**。

## 0. 一页的骨架（顺序固定）

1. `banner`：标题 + 一句钩子 + **「读完这页你能…」**（3 条可检验的能力，别写"了解…"）
2. 导语 `callout(tone="info", title="① 这一页讲什么…")`：为什么关心 + 本页主线 + 建议读法
3. `concept_cards`：4 张卡（图像/机制/定量/代价）
4. `callout(tone="tip", title="③ 调参前先看这里")`：三个滑块各是什么、先动哪个、为什么
5. 读数卡 + 图（每张图配 `figure_note`「看图要诀」三句）
6. `derivation`：脉络 lead + 每步 2-4 句详解 + 结论落回读数卡 + `deep_dive`
7. `tryout`：每个任务 **动机 / 做法 / 看什么 / 说明什么 / 如果没看到…**
8. `quiz`：解析要含**错误选项辨析**
9. 小结：核心机制 / **常见误解** / 真实器件里什么样 / 下一步

## 1. 写作要求

- **多用第二人称和动作动词**（"你拖 amp 时…"），少用名词堆砌。
- **每个抽象结论配一个可验证的锚点**："图 A 的暗脊"、"读数卡的 θ"、"第 5 步的 sin²"。
- **给数字**：量级、典型值、比值（"α ≈ −0.3 GHz"、"门时间几十 ns"）。没有数字的原理讲解等于没讲。
- **给类比**（1 句即可，别堆砌）：「旋钮的刻度」「绕远路攒下的相位」「碎屑转几千圈」。
- **写清楚失效条件**：RWA 要 ω_d ≫ Ω_R；两能级投影要 |α| 足够大；面积定理对形状不敏感但泄漏对形状敏感。
- **常见误解要显式纠正**（用 `deep_dive(..., tone="warn")` 或 `callout(tone="warn")`）：
  "θ=2π 不等于什么都没做"、"adiabatic 不是越长越好"、"ZZ 不是噪声是可预测的相位"。

## 2. 组件的元组形状（写错会 BoundsError）

| 组件 | 元素形状 |
| --- | --- |
| `concept_cards` | `(标题, HTML正文)` —— **二元组** |
| `derivation` | `(操作, 公式, 说明)` —— **三元组**；没有公式也要凑（公式位放公式、说明位放注释） |
| `tryout` | `(标题, 做法, 预期现象)` —— **三元组** |
| `quiz` | `(问题, 选项数组, 正确序号, 解析)` —— **四元组** |
| `deep_dive` | `(标题, 正文; tone)` —— tone ∈ detail/warn/tip |

## 3. 公式（LaTeX）五条纪律 —— 违反会静默坏掉

1. 必须 `tex()`（行内）/ `texblock()`（独占一行），它们带 `class="tex"`（Pluto 只对这个 class 调 MathJax）
2. 定界符用 `\(` `\)`，**不用 `$`**（Julia 字符串里 `$` 触发插值）
3. **含反斜杠的 LaTeX 用 `raw"..."`，里面写单反斜杠**：`\theta`、`\frac{}{}`
   - `raw` 字符串不做转义，写 `\\theta` 会原样进 LaTeX → MathJax 渲染成换行
   - 只有 LaTeX 的换行/矩阵行分隔 `\\` 才写双反斜杠（后面跟空格或 `&`）
4. **数学里不许出现中日韩字符**（MathJax 数学字体无 CJK 字形 → 静默缺字）；
   中文放 math 外面用 `$(tex(...))` 混排
5. 用到 `HTMLStr` 的插值时靠 `Base.string` 方法（已定义），别手动 `.s`
